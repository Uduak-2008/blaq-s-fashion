Blaq's Fashion

A luxury evening gown e-commerce landing page built with plain HTML and CSS (plus a tiny bit of JavaScript for the splash screen). Designed and coded from scratch as a self-taught frontend project.

*Live site:* https://uduak-2008.github.io/blaq-s-fashion/

## Features

- *Splash screen* that shows the brand for a couple of seconds before revealing the site
- *Pure CSS dropdown menu* (hamburger icon using the checkbox technique, no JavaScript needed)
- *Responsive product grid*: 2 cards per row on phones, 4 per row on tablets, laptops and desktops
- *Product cards* with colors matched to each dress, equal-height layout and hover effects
- *Product detail pages* with description, Buy and Add To Cart buttons
- *Luxury dark theme* using CSS variables, a navy and gold palette and the Dancing Script Google Font
- *Centered footer* with brand name and copyright

## Run Locally

1. Clone the repository:
   
   git clone https://github.com/uduak-2008/blaq-s-fashion.git
   
2. Open the folder in your code editor.
3. Open index.html in a browser, or use the Live Server extension in VS Code.

No build tools or installs are needed.

## Deployment

The site is hosted on *GitHub Pages*. Push changes to the main branch and the live site updates after a minute or two.
